# Historical art direction / v4–v5

The earlier interfaces drew on [cyberspace.online](https://cyberspace.online/), a [cyberpunk UI design guide](https://www.youtube.com/watch?v=yLdJh2_-o8U), and [Cyberpunk 2077 accessibility examples](https://www.cyberpunk.net/en/news/49591/update-2-1-accessibility-features). These references informed the navigation, modular panels, typography, colors, and focus states. The interface uses original code and does not reuse reference assets or community content.

The archived `assets/night-city-builder.png` is fictional concept art, not a portrait or a photograph of a build. It is not loaded by the current interface. See [PHOTO-CREDITS.md](PHOTO-CREDITS.md) for the active background photograph and [ART-DIRECTION-V6.md](ART-DIRECTION-V6.md) and [ART-DIRECTION-V8.md](ART-DIRECTION-V8.md) for later artwork.
